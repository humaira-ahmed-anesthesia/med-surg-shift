# Med-Surg Shift

A cozy nursing time-management game, in the spirit of cooking games like Cooking Fever, but the "recipes" are real nursing interventions.

**Play:** open `index.html` in a browser, or play it on GitHub Pages once that's turned on.

## How it plays
- You're the nurse on 4 West with 3 patients. A 12-hour shift (07:00–19:00) lasts about 3 minutes.
- A guided tutorial, then three floor levels (Day shift on 4 West, Busy Monday, Short-staffed Saturday), each with its own patients and emergencies.
- **Rapid Response Nurse:** one patient at a time across the hospital. Run a pulseless VT code and an asystole/PEA code from hyperkalemia (CPR cycles you can fast-forward, shocks, epinephrine, amiodarone, H's and T's), a stroke to CT and TNK, and a liver transplant hemorrhage with massive transfusion (whole blood, PRBCs, plasma, platelets, cryo) before rushing to surgery. Call for more help brings the code team, stroke team or blood bank. If you're too slow, the patient expires.
- A vitals monitor refreshes on its own. Abnormal numbers turn red, and some emergencies start with a vitals check.
- Assess every patient once a shift (an orange ring means not yet). Some problems start with an assessment, like a respiratory exam before a neb.
- Each patient has a problem and a short chain of care (for example, low hemoglobin: type & screen → large-bore IV → hang PRBCs). The next step glows; tap the matching tool at the bottom. The feed lists what everyone needs, but you have to go to each room yourself.
- Health bars drain while patients wait. Tap a patient on the right to go to their room.
- Emergencies happen: desats, bleeding, sepsis, opioid oversedation, A-fib with RVR, allergic and transfusion reactions, hypotension, wound dehiscence, strokes, STEMIs and severe hypoglycemia.
- Some patients need the ICU no matter what. Call the rapid response team or charge to escalate in time.
- Some emergencies need more than the floor: rush them to the OR, CT or the cath lab.
- Each patient has an H&P folder (history of present illness, home meds, allergies, social history, exam, plan) and a log of the shift. The game pauses while it's open.
- Earn slow moments by sending patients home or getting them where they need to go. Tap the snail to slow time for 15 seconds.
